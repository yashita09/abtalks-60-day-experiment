# AI Usage Log — ABTalks

## Project

**ABTalks — 60-Day Developer Experiment**

ABTalks was developed as a vibe-coded hackathon project with AI assistance.

The AI assistant was used for ideation, product architecture, implementation guidance, debugging, UI development, and iteration.

---

## AI Tool Used

**ChatGPT**

## Development Process

The project was developed through an iterative conversation with ChatGPT.

The main development stages were:

1. Define the ABTalks product concept.
2. Design the 60-day developer self-discovery experience.
3. Create the Vite + TypeScript project.
4. Build the landing page and Day 1 mission.
5. Implement the Intent → Build → Evidence → Reflection workflow.
6. Implement the developer signal engine.
7. Implement developer identity classification.
8. Implement the adaptive experiment engine.
9. Implement Day 2 experiments.
10. Implement the Evidence Vault.
11. Implement the 60-day timeline.
12. Debug TypeScript and Vite build errors.
13. Test the complete Day 1 → Adaptive Experiment → Day 2 flow.
14. Create the project README.
15. Prepare the production build.

---

## Key Prompts / AI Assistance

### Product Concept

> Help design ABTalks as a 60-day self-discovery experiment that helps students discover what kind of developer they are through intent, building, evidence, reflection, and adaptation.

### UI Development

> Build a modern, mobile-first interface for the ABTalks 60-day developer experiment with a landing page, Day 1 mission, developer identity dashboard, timeline, and evidence vault.

### Signal Engine

> Implement a developer signal engine that analyzes experiment input and produces signals for Creative, Systems, Data, and Problem Solving.

### Identity Engine

> Create an identity system that uses the strongest developer signal to determine a current identity such as Creative Builder, Systems Thinker, Data Explorer, Problem Solver, or Hybrid Builder.

### Adaptive Engine

> Make the next experiment adaptive based on the user's weakest current signal so that ABTalks collects evidence about areas that have not been explored enough.

### Evidence Vault

> Add an evidence history that stores completed experiments, evidence, builds, signal scores, identities, and dates using browser localStorage.

### Debugging

> Help debug TypeScript syntax errors and Vite production build errors while preserving the existing ABTalks functionality.

### Final Testing

> Test the Day 1 → Adaptive Experiment → Day 2 workflow and verify that signals, identity, evidence, timeline, and localStorage update correctly.

## AI-Assisted Debugging

During development, several TypeScript syntax errors were encountered.

ChatGPT helped identify and correct:

* Incorrect TypeScript type-casting syntax.
* Day 1 / Day 2 selector mismatches.
* Signal bar DOM update syntax.
* Event-handler placement issues.
* Cascading TypeScript parser errors.

The final production build was verified using:

```bash
npm run build
```

The build completed successfully with Vite.
