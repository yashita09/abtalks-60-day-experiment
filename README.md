# 🚀 ABTalks — 60-Day Developer Experiment

> **Don't guess what kind of developer you are. Build evidence and discover it.**

ABTalks is a 60-day self-discovery experiment designed to help students understand what kind of developer they naturally enjoy becoming.

Instead of assigning a fixed personality or asking users to choose a career path, ABTalks uses a continuous loop:

**Intent → Build → Evidence → Reflection → Adaptation**

Every experiment creates new evidence. That evidence influences the next experiment, allowing the user's developer identity to evolve over time.

---

## 💡 The Problem

Students often learn many technologies without knowing which type of development actually fits them.

They may ask:

* Am I better at frontend development?
* Do I enjoy backend systems?
* Am I interested in data?
* Do I enjoy solving complex problems?
* What kind of developer could I become?

Traditional quizzes provide a label based on answers.

**ABTalks takes a different approach.**

Instead of asking:

> "What kind of developer are you?"

ABTalks asks:

> **"What happens when you actually build?"**

---

## 🧪 How ABTalks Works

### 1. Intent 🎯

The user describes what they want to explore.

### 2. Build 🛠

They turn that curiosity into something real.

### 3. Evidence 📸

They record what they actually built or accomplished.

### 4. Reflection 🪞

They reflect on what the experiment taught them.

### 5. Adaptation 🧭

ABTalks analyzes the accumulated signals and recommends the next experiment.

This creates a continuous learning loop:

```text
       ┌──────────┐
       │  INTENT  │
       └────┬─────┘
            ↓
       ┌──────────┐
       │  BUILD   │
       └────┬─────┘
            ↓
       ┌──────────┐
       │ EVIDENCE │
       └────┬─────┘
            ↓
       ┌───────────┐
       │ REFLECT   │
       └─────┬─────┘
             ↓
       ┌────────────┐
       │  ADAPT     │
       └─────┬──────┘
             ↓
       Next Experiment
             │
             └──────────→ repeat
```

## 🧠 Developer Signal Engine

ABTalks currently evaluates four major signals:

| Signal             | What it represents                                      |
| ------------------ | ------------------------------------------------------- |
| 🎨 Creative        | Design, UI, UX, frontend and visual thinking            |
| ⚙️ Systems         | Backend, APIs, databases, architecture and logic        |
| 📊 Data            | Data analysis, Python, statistics and patterns          |
| 🧠 Problem Solving | Debugging, algorithms, research and practical solutions |

The application analyzes the language used across the user's experiment and generates signal scores.

The strongest signal becomes the user's current developer identity.

Possible identities include:

* **Creative Builder**
* **Systems Thinker**
* **Data Explorer**
* **Problem Solver**
* **Hybrid Builder**

> These are signals, not permanent labels.

---

## 🧭 Adaptive Experiment Engine

The most important feature of ABTalks is the **Adaptive Engine**.

After completing an experiment, ABTalks identifies the weakest current signal and creates a new experiment designed to collect evidence in that area.

For example:

```text
Day 1
Creative Builder
       ↓
Systems signal is weakest
       ↓
Adaptive Engine
       ↓
Systems Thinking experiment
       ↓
Day 2
Systems Thinker
```

This means the product doesn't simply tell users who they are.

**It creates experiments that help them discover who they could become.**

---

## 📸 Evidence Vault

Every completed experiment can contribute evidence to the user's personal evidence history.

The Evidence Vault stores:

* Day number
* What was built
* Evidence submitted
* Developer identity
* Signal scores
* Completion date

This transforms the user's journey from a simple streak into a collection of proof.

---

## 📈 60-Day Timeline

The experience is structured around a 60-day journey:

* **Day 1** — Discover
* **Day 2** — Experiment
* **Day 3** — Build
* **Days 4–7** — Find Your Pattern
* **Days 8–30** — Go Deeper
* **Days 31–60** — Developer Identity

The goal is not to produce a final label immediately.

The goal is to let the identity become clearer as evidence accumulates.

## 🚀 Getting Started

### Prerequisites

Make sure you have:

* Node.js
* npm

### Installation

Clone the repository:

```bash
git clone https://github.com/yashita09/abtalks-60-day-experiment.git
```

Move into the project:

```bash
cd abtalks-60-day-experiment
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL shown by Vite, usually:

```text
http://localhost:5173/
```
